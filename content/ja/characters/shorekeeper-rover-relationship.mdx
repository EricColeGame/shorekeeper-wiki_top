鳴潮において、ショアキーパーと漂泊者の関係ほど静かな情緒的重量を帯びた絆はそう多くない。彼女は、自分を覚えていない誰かを信じられないほど長い時間待ち続けた守護者であり、彼は、かつて自分がその世界にとって何を意味していたのかも知らないまま、そこへ歩み戻ってきた記憶喪失の放浪者だ。献身と忘却が出会うこの緊張感こそ、ショアキーパーと漂泊者の関係が黒海岸のストーリーの中心に位置する理由であり、多くのプレイヤーがその章を終えたあと心を揺さぶられる理由でもある。

## ショアキーパーと漂泊者とは？

二人の関係を読む前に、それぞれが実際に何者なのかを知っておく必要がある。彼らは同じ物語の対極に立っている。旅する者と、留まる者だ。

### 漂泊者：歴史に穴の空いた主人公

漂泊者はプレイヤーキャラクターであり、ゲーム開始時に選ぶ共鳴者で、男性版と女性版が存在する。記憶を失った状態で浜辺に打ち上げられ、音骸を吸収しながら、放浪する記憶喪失者にあるはずのないほど重要な過去を少しずつ取り戻していく。漂泊者の元素形態はビルド次第で回折と消滅の間で切り替わり、武器は迅刀を扱う。

### ショアキーパー：留まった者

ショアキーパーは5★の回折属性共鳴者で、増幅器を扱い、黒海岸の管理者を務める。バージョン1.3のストーリーで黒海岸地域とともに登場した。漂泊者が放浪するのに対し、ショアキーパーはその場に留まり続ける——自らが守る海岸に錨を下ろし、不安定な無音領域を監視し、組織を支えている。

| 項目 | 漂泊者 | ショアキーパー |
|---|---|---|
| 役割 | プレイヤー主人公、フィールド上のアタッカー | 5★回折属性のサポート兼ヒーラー |
| 武器 | 迅刀 | 増幅器 |
| 所属 | 黒海岸（遠い過去の創設者） | 黒海岸（管理者にして守護者） |
| 相手の記憶 | 開始時点ではなし | 完全かつ詳細 |
| 初の画面上の出会い | バージョン1.0の冒頭 | バージョン1.3の黒海岸編 |
| フィールド滞在時間 | 長い——漂泊者は画面に立つことが前提 | 短い——ほぼオフフィールドで機能する |

## ショアキーパーと漂泊者の関係を支える設定

二人の絆の土台は非対称性にある。漂泊者は、もうアクセスできない人生の中で黒海岸の設立を支え、ショアキーパーはその遺産を守り続けることを託された。彼女はかつての漂泊者を覚えているが、漂泊者にとって彼女は、自分よりもはるかに大きな何かとして扱われるだけの見知らぬ相手にすぎない。

だからこそ、ショアキーパーと漂泊者の関係は物語装置として非常に効果的なのだ。それは共有された出番や軽口の上に築かれたものではない。一方通行の記憶と、見返りを必要としない忠誠の上に築かれている。

| ストーリーのポイント | 何が起きるか | なぜ重要か |
|---|---|---|
| 物語以前 | 漂泊者が黒海岸の設立を助け、その管理を託す | プレイヤーの記憶より前から続く絆を生み出す |
| 長い待機 | ショアキーパーは持ち場に留まり、無音領域を見守る | 彼女の献身は近さではなく忍耐によって定義される |
| バージョン1.3 | 漂泊者が黒海岸に到着し、彼女と出会う | 再会は対等ではない——彼女は相手を覚えているが、相手は覚えていない |
| 危機 | 黒海岸への脅威が彼女を行動に駆り立てる | 漂泊者を守ろうとする本能が暗黙ではなく明示的になる |
| その後 | 漂泊者が二人の過去をさらに組み立てていく | 絆を、漂泊者自身が選び直すべきものとして捉え直す |

黒海岸そのものが、この物語における一人のキャラクターのように機能する。そこは、漂泊者の忘れられた権威が今もこだまする場所であり、ショアキーパーが存在する理由そのものでもある。

## 二人の絆を決定づけるストーリーの名場面

バージョン1.3の章は、ショアキーパーと漂泊者の関係が最も明示的に描かれる場面である。ストーリーは、漂泊者を、思い出せない人生の結果を目の当たりにする立場に置き、ショアキーパーには、通信チャンネル越しの声以上の存在になる機会を与える。

感情的な重みの大部分を担っているのは、繰り返し現れるいくつかのテーマだ。

| テーマ | どのように現れるか |
|---|---|
| 義務と願望 | 彼女は持ち場に縛られているのに、意識はいつも漂泊者へと流れていく |
| 記憶とアイデンティティ | 思い出せない絆が今も本物と言えるのか、漂泊者は決断を迫られる |
| 待つこと | 彼女というキャラクターを象徴するイメージ——ただ留まり続けた者 |
| 保護 | 漂泊者を守ろうとする本能が、何度も手順や規則を上回る |

コミュニティの報告では、再会の瞬間、彼女が身を危険にさらす場面、そしてその後の静かな会話——漂泊者が何が犠牲にされたのかを理解し始める場面が、この章の感情的なピークとして一貫して挙げられている。どの場面が最も響くかはプレイヤーによって異なるが、この章が漂泊者を白紙の主人公から、悼む価値のある歴史を持つ存在へと描き直すことには、ほぼ全員が同意している。

## 戦闘でショアキーパーが漂泊者を支える仕組み

ショアキーパーと漂泊者の関係は、テーマ面だけでなく、仕組みの面でも重要だ。彼女はゲーム内でも最強クラスのサポートであり、フィールド滞在時間をほとんど必要としないため、漂泊者中心の編成と自然に噛み合う。

| 彼女が提供するもの | おおよその仕組み | 漂泊者にどう役立つか |
|---|---|---|
| 持続回復 | チームに追従する持続的な回復フィールド | 長いコンボやボスのギミックの中でも漂泊者を生かし続ける |
| クリティカル率とクリティカルダメージのバフ | 固有バフが共鳴効率に応じてスケールする | 漂泊者のダメージウィンドウすべての価値を倍増させる |
| エネルギー支援 | チーム全体のローテーション速度を向上させる | アルティメットが早く回り、バースト局面が増える |
| オフフィールドでの貢献 | 役割を果たすのにほとんど画面時間を要しない | 漂泊者が戦闘の主役であり続けられる |

| 編成スタイル | 典型的な構成 | 彼女の役割 |
|---|---|---|
| ハイパーキャリー | メインアタッカー1、サブDPS1、ショアキーパー | 唯一のヒーラー兼バッファー |
| 漂泊者特化 | 漂泊者、ショアキーパー、柔軟なサブDPS | 漂泊者のフィールド稼働時間を最大化 |
| クイックスワップ | 短時間火力のアタッカー2〜3、ショアキーパー | すべてのローテーションに安定してバフをかける |

実践的な結論：漂泊者を軸にしたいなら、ショアキーパーは最もクリーンな支え手の一人だ。彼女は漂泊者とフィールド時間を争わず、バフはどのみち彼女に積むステータスでスケールする。

## カノンとコミュニティ：プレイヤーはこの絆をどう読むか

ネットでショアキーパーと漂泊者の関係を検索すると、まったく異なる二つの会話が同時に起きているのがわかる。一つは設定の議論。もう一つはカップリングの議論だ。どちらも妥当だが、同じものではない。

| 側面 | ゲームが確定していること | コミュニティの解釈 |
|---|---|---|
| 情緒的な近さ | 深い忠誠と保護本能 | しばしば恋愛的に読まれる |
| 相互性 | 漂泊者の感情は意図的に開かれたまま | プレイヤーはしばしば相互の愛情を投影する |
| ラベル | 守護者、管理者、仲間 | ファン界隈では「公式カップル」 |
| トーン | 抑制され、物悲しい | ファンアートや編集動画、二次創作で拡張される |

コミュニティの報告によれば、この曖昧さは意図的なものだ。鳴潮は感情の山場を明言するよりも控えめに描く傾向があり、それがプレイヤーの空白を埋める余地を生んでいる。その抑制こそが、これほど多くの議論を生む燃料になっている。

正史版の出来事を知りたいなら、黒海岸編と彼女のキャラクターストーリーを順番にプレイしよう。ファンダム版が欲しいなら、検索バーが残りを引き受けてくれる。

## 二人の物語を味わうための実践的なヒント

- **黒海岸のストーリーを順番にプレイする。** バージョン1.3のカットシーンを飛ばすと、ショアキーパーと漂泊者の関係に重みを与える文脈が失われる。
- **ショアキーパーのキャラクターストーリーをクリアする。** メインクエストがほのめかすだけの細部を補完してくれる。
- **大きな場面だけでなく、静かな場面も見る。** 二人の関係性の多くは、見せ場ではなく小さな会話の中に宿っている。
- **漂泊者の序盤の会話を見返す。** 物語の結末を知っていると、序盤の記憶喪失の描写が二周目では違って響く。
- **公式の鳴潮サイトをチェックする** ストーリーの更新やキャラクター詳細はこちら：[鳴潮公式サイト](https://wutheringwaves.kurogames.com/en/main)。

編成については、優先順位はシンプルだ。ショアキーパーは共鳴効率を最優先で積む——バフがそれに応じてスケールするからだ。その後、彼女のローテーションの隙間を埋められるサブDPSを漂泊者に組み合わせよう。

## FAQ

**ショアキーパーと漂泊者の関係は恋愛なのか？**
ゲームは曖昧なままにしている。ショアキーパーの漂泊者への忠誠と保護本能は紛れもないが、鳴潮がこの絆を明示的に恋愛とラベル付けすることは一度もない。コミュニティの報告では広くそう解釈されているが、それはカノンではなく解釈だ。

**二人の絆を理解するには黒海岸編をプレイする必要がある？**
はい。ショアキーパーと漂泊者の関係は、ほぼすべてそのストーリーと彼女のキャラクタークエストで描かれる。それを抜きにすると、彼女は興味深いボイスラインを持つサポート枠にしか見えず、歴史を持つキャラクターには見えない。

**漂泊者編成にショアキーパーは必須？**
必須ではないが、極めて便利だ。回復し、クリティカル率とクリティカルダメージをバフし、フィールド時間をほとんど取らないので、漂泊者を運転席に留めておける。他のサポートでも機能するが、これほどきれいに噛み合う者は少ない。

**プレイする漂泊者によって関係は変わる？**
意味のある形では変わらない。ストーリーは選んだ形態に関係なく漂泊者を漂泊者として扱うため、ショアキーパーと漂泊者の関係は誰にとっても同じように展開する。
