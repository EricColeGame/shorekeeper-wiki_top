## ショアキーパーのスキルが生のダメージ以上に重要な理由

ショアキーパーのスキルは、自身がダメージ競争に勝つためではなく、他の全員を勝たせるために設計されている。サポートがフィールドに出た瞬間にチームのダメージが跳ね上がるのを見たことがあるなら、ショアキーパーのスキルの価値はすでに理解しているはずだ。彼女は鳴潮に登場する黒海岸の謎めいた守護者であり、そのキットは純粋な回復をチーム全体のダメージ倍率へと変えてしまう。

この違いは言葉の印象以上に重要だ。鳴潮は緻密なローテーションと素早いスワップを評価するため、世話が必要なサポートは足手まといになる。ショアキーパーはその逆だ。彼女のキットは、出す・撃つ・交代するだけで完結するように作られており、メインアタッカーが主力を担っている間も回復フィールドとバフが働き続ける。

彼女の価値は紙の上では過小評価されやすい。ダメージランキングの頂点に立つことはなく、専任のDPSと並べると本人の数値は控えめに見える。代わりに彼女が行うのは、周囲の全員の上限を引き上げることだ。持続する回復フィールドが場に出ているキャラクターを健康に保ち、チーム全体のバフ時間がすべての一撃をより強くする。

この組み合わせこそ、彼女がこれほど多くのエンドコンテンツクリアで起用される理由だ。一度のミスでランが終わるモードでは、単発のバーストではなく継続的に回復するサポートは、どれだけ攻め気味に立ち回れるかを変えてくれる。ダメージを出す時間から逃げるのをやめ、その中に立ち続けられるようになる。

先に進む前にひとつ。正確なツールチップの数値はパッチごとに調整される。以下の具体値は方向性として捉え、最新の数値は[鳴潮 公式サイト](https://wutheringwaves.kurogames.com/en/)やゲーム内のキャラクター画面で確認してほしい。

## ショアキーパーのスキル早見表：各スロットの解説

彼女のキットは小技が少なく、信頼性が高い。各パーツの役割と、なぜ採用に値するのかをまとめた。

| スキルスロット | 効果 | 重要な理由 |
|---|---|---|
| 通常攻撃 | 短い回折コンボで、フォルテのリソースも溜まる | クールダウン中に待機せずリソースを貯められる |
| 共鳴スキル | 場に出ているキャラクターの周囲に回復フィールドを展開 | 彼女に再度スワップすることなく継続回復が可能 |
| フォルテ回路（洞察） | 蓄積したリソースを消費して回復とバフ出力を強化 | 最も強力なサポート時間を生み出すエンジン |
| 共鳴解放 | チーム全体の大回復と、味方を強化する持続フィールド | 緊急時の切り札とバフ付与を1回で兼ねる |
| 登場スキル | 登場時にダメージを与え、サポート効果を付与 | 彼女へのスワップがほぼノーコストに感じられる |
| 退場スキル | チーム全体に会心率と会心ダメージを付与 | 彼女が編成に入る最大の理由 |

際立つ点が2つある。第一に、彼女のキットのほとんどは彼女が場に留まることを必要としない。回復フィールドとバフは彼女が離れた後も作動し続ける。第二に、退場スキルが報酬であり、それ以外のすべてはそれをチャージし、それが発動するまでチームを生存させるために存在する。

## 洞察メカニクスの実践的な仕組み

洞察は、動きがぎこちないショアキーパーと、自動的に回るショアキーパーを分けるリソースだ。通常攻撃とスキルでこれを蓄積し、上限まで保持したうえでフォルテ回路で消費し、強化された回復とバフ効果を発動する。

ループは単純だが、順序が重要だ。

| フェーズ | やること | 目的 |
|---|---|---|
| 蓄積 | クールダウン中に通常攻撃とスキルを使用 | 場にいる時間を無駄にせず洞察を溜める |
| 消費 | リソースが整ったらフォルテ回路を発動 | リソースを回復とバフの稼働時間に変換 |
| 引き継ぎ | 退場スキルでスワップアウト | 会心バフをメインアタッカーに渡す |

よくあるミスは、洞察を溜め込むバースト用リソースのように扱うことだ。実際には、コミュニティの報告によれば、こまめに消費することで回復フィールドが更新され続け、バフ時間がDPSローテーションとずれるのを防げる。

もうひとつのミスは、居座りすぎることだ。ショアキーパーの通常攻撃は目的達成の手段にすぎない。メインアタッカーがベンチにいるのに彼女で通常攻撃を続けているなら、リソース獲得分以上のダメージを失っている。

## バフ、スケーリング、共鳴効率：本当に重要なもの

ショアキーパーのスキルは回復とバフという2つのスケーリング系統に分かれており、求めるステータスが異なる。だからこそ、多くのカジュアルなビルドが彼女を間違える。

彼女の回復は自身の耐久系ステータスでスケールし、治療効果で増幅されるため、攻撃力を積んでもほとんど意味がない。一方、バフは共鳴効率でスケールする。共鳴効率が高いほどサポート性能が上がり、さらにアルティメットをより頻繁に撃てるという明白な利点も得られる。

| ステータス | キットへの効果 | 優先度 |
|---|---|---|
| 共鳴効率 | アルティメットの回転率を支え、会心バフをスケールさせる | 最優先 |
| HP% | 回復量の主要な伸び幅 | 高 |
| 治療効果 | すべての回復を直接増幅 | 高 |
| 固定HP | 効果は小さいが回復量を底上げ | 中 |
| 攻撃力% | 回復もバフもほぼ変化しない | 低 |
| 会心率／会心ダメージ | 本人のダメージにしか影響しない | 低 |

バフが共鳴効率でスケールするため、多くのコミュニティビルドは一般的なキャラクターの基準値である100%をはるかに超えてこのステータスを伸ばす。ショアキーパーの回復は問題ないのにバフが弱いなら、ほぼ間違いなく共鳴効率が原因だ。

## ローテーションと編成シナジー：キットを活かす

ショアキーパーはほぼどの編成にも収まるが、増幅すべき明確なダメージ時間が1つある編成で最も輝く。彼女のバフはチーム全体に及ぶため、単一のハイパーキャリーを軸にした構成が最も恩恵を受ける。

| 編成タイプ | 彼女の役割 | 備考 |
|---|---|---|
| 単一ハイパーキャリー | バフを1つのDPS時間に集中 | 上限が最も高く、タイミングも合わせやすい |
| 2アタッカー | バフが2人のアタッカーをカバー | 集中力はやや落ちるが柔軟性が高い |
| クイックスワップ | 回復フィールドが攻めのスワップを安全に | 速く自信のある立ち回りを後押し |
| ボス戦 | 継続回復が長期戦を安定させる | 完璧な回避への依存を軽減 |

実践的なローテーションを平易にまとめると：

- ショアキーパーから開始し、スキルで回復フィールドを設置する。
- 短い通常攻撃のコンボで洞察を溜める。
- フォルテ回路を発動し、リソースをサポート効果に変換する。
- アルティメットを撃ち、チームを回復してバフ時間を開始する。
- 退場スキルでスワップアウトし、アタッカーに会心バフを引き継ぐ。
- フィールドの更新やリソースの再構築のためだけに彼女へ戻る。

コミュニティ全体のプレイヤー体験はここでおおむね一致している。アルティメット直後にショアキーパーからスワップアウトするチームは、彼女に居座るチームよりも綺麗なダメージ時間を得やすい。

## ショアキーパーのスキルを軸にしたビルド：音骸、武器、ステータス

彼女のキットはダメージよりも共鳴効率と回復を重視するため、ビルドは異例なほど寛容だ。完璧な会心厳選を追いかける必要はない。

| スロット | 求めるもの | 理由 |
|---|---|---|
| 武器 | 共鳴効率か治療効果を持つ増幅器 | どちらのステータスもサポート役に直結する |
| 音骸セット | 治療効果と共鳴効率を持つサポート向けセット | キットがスケールする2つのステータスを増幅 |
| メインステータス | 共鳴効率、HP%、治療効果 | 回復とバフのスケーリングに合致 |
| サブステータス | 共鳴効率 → HP% → 固定HP | 実際の性能への影響順 |
| 編成での役割 | 単独サポート、または2人目のヒーラーと併用 | ほとんどのコンテンツを単独でサポートできる |

実践的なヒントをいくつか：

- 意図的にダメージ特化型を組むのでなければ、彼女に会心を追わせないこと。ほとんど報われない。
- 共鳴効率が足りないなら、何よりも先にそこを直すこと。キットの両方の側面に影響する。
- その場に留まってダメージを出したいキャラクターと組ませる。彼女の回復フィールドは踏みとどまるほど報いてくれる。
- DPSの時間を計画するときは、彼女のスキルとアルティメットのクールダウンを基準に考える。逆ではない。

## よくある質問

**ショアキーパーのスキルは攻撃力とHPのどちらでスケールしますか？**
回復は主に自身の耐久系ステータスと治療効果でスケールし、攻撃力ではありません。攻撃力を積むのは、プレイヤーが彼女で最もよくやるビルドミスの一つです。

**ショアキーパーには共鳴効率がどれくらい必要ですか？**
一般的なキャラクターより多く必要です。会心バフが共鳴効率でスケールするうえ、通常のアルティメット回転率の恩恵もあるため、コミュニティのビルドは標準的な基準値をはるかに超えて伸ばす傾向があります。

**ショアキーパーはヒーラーですか、それともバッファーですか？**
両方です。回復フィールドがチームを継続的に生存させ、退場スキルがチーム全体に会心率と会心ダメージのバフを付与します。この二重の役割こそ、ショアキーパーのスキルがエンドコンテンツで高く評価される理由です。

**ショアキーパーのスキルは2人目のヒーラーの代わりになりますか？**
ほとんどのコンテンツでは、はい。継続回復はチームを単独でサポートできるほど強力で、3枠目を別のアタッカーやサブDPSに回せます。
