## ショアキーパーのファンアートが際立つ理由

10人のアーティストに彼女を描かせれば、10通りの雰囲気が生まれます——しかし最も強い作品は、認識できるカテゴリーに分かれる傾向があります。これらのスタイルを知っておくと、より正確に検索でき、自分で描く場合は自分の強みに合った方向性を選べます。

| スタイル | 強調するもの | 必要スキル |
|---|---|---|
| 幻想的なソフトシェーディング | 光、グラデーション、夢のようなライティング | 中級 |
| クリーンな線画 | 正確なシルエットと衣装のディテール | 初心者向け |
| ドラマチックなキーアート | 映画的な構図、強いコントラスト | 上級 |
| ちびキャラとステッカーアート | かわいい比率、表情豊かな顔 | 初心者向け |
| 絵画的なリアリズム | 質感、解剖、雰囲気の深み | 上級 |
| ミクストメディア | 水彩、インク、コラージュ表現 | さまざま |

いくつかの視覚要素はとても効果的なため、繰り返し現れます。髪に沿ったリムライト、1つの暖色アクセントで引き締めたクールな配色、光を描き込むのではなく示唆するために使われるネガティブスペースなどです。

### 優れた作品から借りた構図のコツ

- **まずシルエット。** 真っ黒に塗りつぶしても形がはっきり読めれば、完成作品でもはっきり読めます。
- **焦点は1つ。** 顔か、光る要素を1つだけ構図の主役にしましょう。
- **配色を絞る。** 2〜3色にアクセントカラー1色を加えたほうが、虹色よりもほぼ常に優れています。
- **背景を使う。** 単純なグラデーションや星野でも、物語性が加わります。

## クレジット表記、転載、アーティストの支援

鳴潮のアートコミュニティは寛容ですが、固い規範があります——破ればブロックや通報につながります。プレイヤーの経験によると、多くのトラブルは悪意ある転載ではなく、単純なルールの無知から始まります。

| すべきこと | すべきでないこと |
|---|---|
| アーティストの元投稿に直接リンクする | 許可なくアートを再アップロードする |
| アイコンやバナーにアートを使う前に許可を求める | 署名やウォーターマークを切り落とす |
| Discordサーバーで共有するときはアーティスト名を記載する | 「Googleで見つけた」を出典だと言う |
| 好きなクリエイターをフォローし交流する | 無断でアートをAI学習データセットに投入する |
| 可能ならコミッションを依頼したりグッズを購入する | 無料リクエストをアーティストに強要する |

元のアーティストが特定できない場合、最も安全なのは転載しないことです。画像逆検索ツールで作品の出所をたどれることが多く、多くのアーティストはプロフィールや自己紹介に転載ポリシーを記載しています。迷ったら尋ねましょう——ほとんどのクリエイターは丁寧な依頼なら喜んで許可してくれます。

## 自分でショアキーパーのファンアートを描く方法

| ステップ | やること | 所要時間の目安 |
