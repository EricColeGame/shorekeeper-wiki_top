## 鳴潮のショアキーパーとは？

ショアキーパーは、ラメントやソラリス3に広がる異常現象を監視する研究組織「ブラックショア」に結びついた存在です。ストーリー上ではブラックショアの中核の管理を担っており、普通の共鳴者ではなく組織のシステムに縛られた存在として、主人公と実際に出会うずっと前から彼を見守っていました。

彼女の魅力は性能面だけではありません。完全な物語のアークとともに登場し、印象的な星をモチーフにしたデザインと、分析的な性格と静かな献身性のあいだに位置する人物像を備えています。

- **所属：** ブラックショア
- **ストーリー上の役割：** ブラックショアの中核を守る守護者であり管理者
- **性格：** 冷静、正確、控えめ、そして深い忠誠心
- **ビジュアルの特徴：** 星の光、深い青、天体を思わせるモチーフ
- **物語上のフック：** 漂泊者の失われた記憶に直接つながっている

こうした設定こそ、ショアキーパーの実装日がこれほど大きな反響を呼んだ理由です。彼女は静かなパッチに放り込まれた穴埋めキャラクターではなく、何か月も前からゲームが匂わせてきたストーリーの答えだったのです。

## ショアキーパーの登場がこれほど衝撃的だった理由

彼女は3つの仕事を同時にこなします。それが今でも攻略記事が彼女を勧め続ける理由でもあります。回復し、バフを配り、ローテーションを滑らかにする。鳴潮のサポーターの多くはそのうちひとつだけを担当します。ショアキーパーは完璧な装備を要求せずに3つすべてをこなします。

| 彼女がもたらすもの | なぜ重要なのか |
|---|---|
| 広範囲にわたる継続回復 | 長期のボス戦や逆境深塔の各フロアでパーティを生存させる |
| パーティ全体の会心率・会心ダメージバフ | 手持ちのすべてのアタッカーの上限を引き上げる |
| 共鳴効率に応じて伸びるバフ | 多くのサポーターが無視するステータスを活かし、育成をシンプルに保つ |
| バフを次へ引き継ぐ終奏スキル | メインアタッカーがすでにバフを受けた状態でコンボを始められる |
| 持続するフィールド効果 | キャラ交代のあいだもバフが切れずに維持される |

彼女の会心バフは自身の攻撃力や会心ステータスではなく共鳴効率に応じて伸びるため、ゲーム内でもっとも安く育てられる高性能サポーターのひとりです。完璧な会心厳選を追う必要はありません。狙うのはひとつの数値だけで、それ以外はすべておまけです。

プレイヤーの実感もこれを裏付けています。ショアキーパーの実装日以降のコミュニティのティア議論では、彼女はヴェリーナと並んでサポーターランキングの最上位に位置し続けており、多くの編成ではヴェリーナを上回っています。

育成方針は驚くほど狭いです。共鳴効率の上限を目指し、HPを積み、それ以外は無視しましょう。

## ショアキーパーの実装日に関するよくある質問

**ショアキーパーの実装日は正確にはいつですか？**
鳴潮バージョン1.3の前半フェーズ、2024年9月下旬に登場しました。これはゲームのグローバルリリースからおよそ4か月後のことで、ブラックショアのストーリーを代表する看板キャラクターとなりました。

**ショアキーパーは限定ガチャのキャラクターでしたか？**
はい。彼女は限定5★のスペクトロ属性・整流器使いで、常設ガチャには決して追加されませんでした。入手する唯一の方法は、開催中に彼女のピックアップガチャを引くことです。

**ショアキーパーは今でも引く価値がありますか？**
ショアキーパーの実装日以降、コミュニティの consensus は一貫しています。答えはイエスです。彼女はほぼすべての編成に収まる汎用ヒーラー兼バッファーであり、共鳴効率とHPさえあればよいため、高性能サポーターの中でもっとも安く育てられるひとりです。

**ショアキーパーは何凸必要ですか？**
無凸で十分です。彼女は共鳴チェーンなしでも完全に機能し、追加の凸は贅沢であって必須ではありません。重複と新キャラクターのどちらを選ぶかで迷ったら、新キャラクターのほうがほぼ常に価値が高いです。
